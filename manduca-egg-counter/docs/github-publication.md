**Описание:** YOLOv8 instance segmentation for counting Manduca sexta eggs in laboratory images, with a Telegram interface.

**Topics:** `computer-vision`, `yolov8`, `instance-segmentation`, `object-counting`, `entomology`, `telegram-bot`, `python`, `research`

**Видимость:** определить с автором до создания удалённого репозитория.
