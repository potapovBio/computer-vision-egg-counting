# Обученная модель

Для распознавания яиц используется checkpoint **YOLOv8m-seg**, обученный на классе `egg`.

Сохраните файл `best.pt` в эту папку и запустите из корня проекта:

```bash
python predict.py examples/input.jpg --weights weights/best.pt
```

Если файл находится в другой папке, передайте его путь через `--weights`. Веса хранятся отдельно от исходного кода. Для обучения собственного checkpoint используйте `train.py` и инструкцию в README.

Стандартные веса `yolov8m-seg.pt` используются как начальная модель для обучения; готовый счётчик требует модели, дообученной на яйцах.
