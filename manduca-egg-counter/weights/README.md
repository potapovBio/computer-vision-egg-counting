# Обученные веса

Для запуска положите проверенный checkpoint модели YOLOv8m-seg с единственным классом `egg` в `weights/best.pt`.

В подготовленной локальной копии файл уже присутствует, но `.gitignore` исключает его из Git. Хеш и размер находятся в `reports/weights.json`. Публичная ссылка на скачивание пока отсутствует. Если репозиторий клонирован с GitHub, запросите веса у автора.

Не заменяйте обученный checkpoint стандартным `yolov8m-seg.pt`: стандартная модель не обучена считать эти яйца. Используйте только доверенные файлы PyTorch.
